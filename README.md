# Cálculo Integración numérica

## Contenido
En este repositorio se encuentra el desarrollo del proyecto 1, cada parte está en un archivo con su nombre correspondiente. Las tablas y gráficas generadas por cada programa se guardan en carpetas con sus respectivos nombres.

## Requerimientos
Para instalar los requerimientos de este proyecto se debe estar en `../tarea-integracion-numerica` y correr en la consola el siguiente comando:
```
pip install requirements.txt
```

## Ejecución de cada programa desde la consola
Para correr cada programa basta con estar en el directorio de `../tarea-integracion-numerica` y correr el siguiente comando:
```
python ./<nombre del programa>
```

## Limitaciones
- En la carpeta `/tablas` debe ya estar creada la carpeta para almacenar las tablas de cada ejercicio.
